# Portnoy — заглушка с 4K

Скопировать всё содержимое `site/` на статический хостинг. `index.html` — чистая страница, `particles.html` — настройка количества и крупности частиц. Сервер должен отдавать `.mjs` как JavaScript, `.mp4` как video/mp4 и поддерживать Range-запросы. Браузеру нужен WebGL2. Внешних CDN и сборки npm нет.

Для обычного просмотра с компьютера использовать автономный `PORTNOY-preview.html`. Настройки вынесены в `PORTNOY-particles.html`. Видео, шрифты и графика в них встроены.

## Зафиксированный вариант

Видео `assets/portnoy-loop.mp4`: 3840×2160, 24 fps, 65 секунд / 1560 кадров. Topaz Precision (Proteus) на fal.ai увеличил Full HD монтаж вдвое; файл для сайта сжат локально, без изменения разрешения, монтажа или частоты кадров. Исходный мастер Topaz сохранён отдельно.

PORTNOY 110%, ширина и интервалы 100%; production по левому краю надписи; лицо 72×92 px на компьютере, 56×72 px на телефоне. Маска 70%, мягкость 85%; фокус «поиск → резкость» и уголки 40%. Мягкий видоискатель. Контакты: канал https://t.me/portnoy_production и info@portnoy.pro.

Кнопка прозрачная, без рамки: при наведении текст перекатывается горизонтально, справа появляется стрелка. Собственная CSS-реализация по визуальному референсу [Sneaky](https://21st.dev/@nextjsshop/components/sneaky-button), закрытый код не копировался. Ссылки раскрываются вертикально, рядом с курсором появляется круг со стрелкой. Клавиатура и Escape поддерживаются; при сокращении движения анимации отключены.

## Частицы

262 144 на компьютере, 65 536 на узком экране. Размер зависит от количества как у Виктора: `size = 9.5 * (1048576 / N)^0.25`; яркость `.045 * sqrt(1048576 / N)`. Выбор в `particles.html` сохраняется локально в браузере и обновляет открытый index того же origin. Для общего пресета изменить defaultParticleCount в движке; локальный ключ — portnoy-placeholder-particles-v1.

## Проверка

Проверяются полное декодирование, длительность, разрешение, количество кадров, выборочные изображения, синтаксис JS, встроенные ресурсы автономных HTML и SHA-256 видео. Полный непрерывный визуальный просмотр и свежая проверка на реальном телефоне в этой сессии не подтверждены: встроенный браузер не завершает навигацию. Новое видео включено в основной пакет по прямому запросу Саши о финальной сборке с апскейлом; это не подменяет визуальную проверку.

Для Тильды: разместить папку на статическом хостинге и встроить index.html в полноэкранный iframe T123 с allow="autoplay; fullscreen", без внешних отступов. Сам HTML с относительными ресурсами целиком в редактор Тильды не вставлять.

https://portnoy.pro/placeholder) с одним блоком T123 (HTML-код), которая назначена
главной 25.10.2026. Старая главная «Portnoy production.» (id 32956649) осталась,
открывается по https://portnoy.pro/page32956649.html. Откат на старый сайт: Настройки сайта → Главная
страница → выбрать прежнюю главную → Опубликовать. Код блока T123:

```html
<style>
  .t-records, .t-body { background: #000 !important; }
  #portnoy-placeholder { position: fixed; inset: 0; width: 100vw; height: 100vh; border: 0; display: block; background: #000; z-index: 9999; }
</style>
<iframe id="portnoy-placeholder" src="https://donitovito.github.io/portnoy-placeholder/" allow="autoplay; fullscreen" allowfullscreen loading="eager" title="Portnoy Production"></iframe>
```

Телефонам и узким экранам отдаётся `assets/portnoy-loop-1080.mp4` (1920×1080,
перекодировано из 4K-мастера Саши, CRF 25), десктопу — исходный 4K.
